# Paper artifacts

The current submission is the IST package under `paper/ist_submission/`.
Build its `main.tex` with `latexmk -pdf -interaction=nonstopmode
-halt-on-error`. Its `VulTriage_IST_manuscript.pdf` is the checked compiled
manuscript, and the accompanying files contain the Elsevier class, bibliography
style, figures, source data, highlights, and cover-letter text.

The legacy `main.tex`, `fcs.cls`, and `fcs.bst` files in this directory are
retained only as historical project scaffolding. They are not the current IST
submission and should not be uploaded to the IST portal in place of the
`ist_submission` package.
