# Paper artifacts

The current submission is the KBS package under `paper/kbs_submission/`.
The earlier IST package under `paper/ist_submission/` is retained for
historical provenance only. Build the KBS `main.tex` with `latexmk -pdf
-interaction=nonstopmode -halt-on-error`. Its `VulTriage_KBS_manuscript.pdf`
is the checked compiled manuscript, and the accompanying files contain the
Elsevier class, bibliography style, figures, source data, highlights, and
cover-letter text.

The legacy `main.tex`, `fcs.cls`, and `fcs.bst` files in this directory are
retained only as historical project scaffolding. They are not the current KBS
submission and should not be uploaded to the KBS portal in place of the
`kbs_submission` package.
