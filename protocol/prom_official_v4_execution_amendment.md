batches, controls and analysis in `prom_official_v4.md` remain fixed. Prior TRACE

not an outcome-blind design or public preregistration.

Literal upstream component execution was completed for the source validation
batch and 43 target project cells of the first fine-tuned fit. The 19,179-function
MegaVul wireshark batch exposes the upstream quadratic pooled-count operation.
The direct process was stopped before outcome evaluation, and its real source
outputs, partial target decisions, implementation/runtime bytes and progress are
preserved in a separate author-side literal-evidence directory.

The authorized optimization operates only inside a copied runtime's
`_compute_p_values`. It sorts the **complete duplicated global calibration
score pool** once, and computes the number of scores greater than or equal to
each test score using `searchsorted(side='left')`. It retains the original total
pool size as denominator. No per-row pool, deduplication, subsampling, altered
neighborhood, batching or statistical quantity is introduced. The unchanged
official source checkout and separate binary one-hot diff remain available.

NaN calibration scores never contribute a successful comparison but remain in
the denominator; a NaN test score receives zero successful comparisons. Positive
and negative infinity retain their original comparison semantics, and an empty
pool retains undefined p-values. The deployable sealed-probability bridge also
rejects nonfinite input probabilities before official scoring.

Execution clearance requires exact direct-versus-optimized native multiclass
and repaired binary equality, repeated-score and boundary-tie tests, allowed
near-boundary scalar alpha checks, NaN/infinity/empty-pool equivalence, and
nonfinite probability rejection. The direct 6,296-row source alpha grid and
every literal target archive must also match the optimized run array for array
before any target-label vault is joined. Any mismatch blocks evaluation. Exact
diffs, runtime hashes, tests and the root clearance receipt are retained.
